# Elle Bâtit

Site vitrine d'une page pour **Elle Bâtit** — « Foi, femme, famille, destinée » : présentation, épisodes, rencontre et réseaux à venir.

## Technologies
- HTML/CSS statique autonome (aucune étape de build), polices Google Fonts
- Un petit script inline pour le compte à rebours et le défilement fluide
- Hébergé sur Netlify (dossier publié : `public/`)

## Lancer en local
Ouvrir `public/index.html` dans un navigateur, ou lancer `netlify dev` depuis la racine.

## Évolutions possibles
- Remplacer les boutons WhatsApp / Instagram / TikTok par de vrais liens quand les comptes ouvriront (section `#suivre`).
